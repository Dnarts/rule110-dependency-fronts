# 110 OBSERVER. Наблюдаемость собственного прошлого

[Читать монографию (PDF)](./110_OBSERVER_Preprint.pdf) · [Исходный текст LaTeX](./main.tex) · [Архив изданий](./archive/README.md)

Когда система может восстановить факт о собственном прошлом, сколько битов ей для этого нужно и как проверить, что она воспользовалась сообщением? Общая теория T1–T4 применяется сначала к Rule 110, где можно проследить возмущение одной клетки, затем к замороженной OLMo, где между эпизодами передаётся один токен. T5–T6 устанавливают границу вывода о субъективном опыте.

**Срез от 20 ноября 2026 г.** Для бесконечной решётки доказано равенство $D_t=I_t$. В Lean 4.35.0 пересобраны 263 модуля геометрии и проверены 11 отчётов об аксиомах модуля наблюдателя. Для OLMo зафиксирована dev-панель двухшагового варианта A. На расходящихся концах доставка дала 64/64 правильных ответа, постоянный токен — 32/64. Статусы отложенных панелей относятся к этому срезу. [Журнал геометрии](./verification/monograph/geometry-axioms.log) · [Журнал наблюдателя](./verification/monograph/observer-axioms.log) · [Dev-отчёт](./observer/two-step-instruct-chat-04/report.json)

Из корня репозитория две команды на Python 3 воспроизводят конечные сертификаты, реестры и подсчёт по сохранённым dev-строкам.

~~~sh
python3 -B observer/verify.py
python3 -B observer/verify_part_iii.py
~~~

Полная пересборка формальных доказательств и эти же проверки объединены в `make verify-series` (Lean 4.35.0 и Python 3.10+). PDF собирается командой `make monograph` (Tectonic либо XeLaTeX с latexmk). Обозначения собраны в §1, спецификация гейтов и команды — в приложении B.
